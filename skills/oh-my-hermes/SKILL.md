# Oh My Hermes — Multi-Agent Orchestration

Multi-agent orchestration skills for Hermes Agent. Inspired by oh-my-claudecode, rebuilt natively for Hermes primitives.

## Structure
- `.omh/plugins/` — Hermes plugins for orchestration
- `.omh/plans/` — Plan templates for multi-agent workflows
- `.omh/research/` — Research skill prompts

## Installation
```bash
git clone https://github.com/witt3rd/oh-my-hermes.git
cd oh-my-hermes
# Install plugins to ~/.hermes/plugins/
# Skills are loaded from .omh/
```

## Key Features
- Native Hermes plugin architecture
- Multi-agent orchestration patterns
- Research and planning workflows
- Inspired by Claude Code's oh-my-zsh patterns but rebuilt for Hermes
