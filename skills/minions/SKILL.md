# Minions — Mission Control for Hermes Agent

One screen to create, supervise, and review autonomous Hermes Agent work. Kanban board, live streaming, human-in-the-loop review, scheduled tasks, and file browser.

## Quick Start

```bash
npx minionsai
```

Open http://localhost:6969

## Features
- **Kanban board** — see every task: in progress, in review, done
- **Autonomous execution** — describe what you want, walk away
- **Live streaming** — watch tool calls, reasoning, and responses in real time
- **Human-in-the-loop** — agents propose completion; you verify
- **Scheduled Tasks** — recurring Hermes jobs with history
- **File browser** — see files agents have created
- **Per-task model control** — override model on any task
- **Local-first** — SQLite, no account, no cloud dependency
