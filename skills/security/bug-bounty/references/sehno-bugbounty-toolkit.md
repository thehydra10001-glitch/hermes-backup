# Sehno Bug Bounty Toolkit

Source: https://github.com/sehno/Bug-bounty/blob/master/bugbounty_toolkit.md

## Recon — Subdomains
- [amass](https://github.com/OWASP/Amass) — Attack surface mapping
- [subfinder](https://github.com/projectdiscovery/subfinder) — Passive subdomain enumeration
- [assetfinder](https://github.com/tomnomnom/assetfinder) — Find subdomains from TLS/cert data
- [dnsgen](https://github.com/ProjectAnte/dnsgen) — DNS permutation generator
- [shuffledns](https://github.com/projectdiscovery/shuffledns) — Mass DNS resolver
- [httprobe](https://github.com/tomnomnom/httprobe) — Probe for live HTTP/HTTPS hosts
- [aquatone](https://github.com/michenriksen/aquatone) — Screenshot tool for alive hosts

## Enumeration / Crawling
- [nmap](https://nmap.org/) — Network scanner
- [ffuf](https://github.com/ffuf/ffuf) — Fast web fuzzer
- [hakrawler](https://github.com/hakluke/hakrawler) — Web crawler
- [gau](https://github.com/lc/gau) — Get All URLs (wayback machine)
- [paramspider](https://github.com/devanshbatham/ParamSpider) — Parameter discovery
- [arjun](https://github.com/s0md3v/Arjun) — HTTP parameter discovery
- [parameth](https://github.com/maK-/parameth) — Parameter brute-forcer

## Manual Recon
- [Shodan](https://www.shodan.io/) — IoT/device search engine
- [Censys](https://censys.io/) — Internet asset discovery
- Google dorks
- [Pastebin](https://pastebin.com/)
- [GitHub](https://github.com)

## XSS
- [xsshunter](https://xsshunter.com) — XSS exfiltration service
- [xsscrapy](https://github.com/DanMcInerney/xsscrapy) — Automated XSS scanner
- [dalfox](https://github.com/hahwul/dalfox) — Fast XSS parameter analyzer

## SQL Injection
- [sqlmap](https://github.com/sqlmapproject/sqlmap) — Automated SQLi exploitation
- [waybackSqliScanner](https://github.com/ghostlulzhacks/waybackSqliScanner) — History-based SQLi scanner
