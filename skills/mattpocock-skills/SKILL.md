# Matt Pocock's Skills For Real Engineers

Skills that solve real software engineering failure modes — not vibe coding. Composable, adaptable, model-agnostic.

## Key Skills

### Engineering (User-invoked)
- `/grill-me` — Grilling session to align before coding
- `/grill-with-docs` — Grilling + build shared language (CONTEXT.md + ADRs)
- `/triage` — Move issues through a state machine
- `/improve-codebase-architecture` — Scan + visual report + fix
- `/to-spec` — Turn conversation into a spec
- `/to-tickets` — Break specs into tickets
- `/implement` — Build from specs using TDD
- `/wayfinder` — Plan huge work as investigation tickets

### Engineering (Model-invoked)
- `/tdd` — Red-green-refactor test-driven development
- `/diagnosing-bugs` — Disciplined diagnosis loop
- `/research` — Investigate questions against primary sources
- `/code-review` — Two-axis review (standards + spec)
- `/domain-modeling` — Build and sharpen domain model
- `/prototype` — Throwaway prototypes for design questions
- `/codebase-design` — Design deep modules

### Productivity
- `/use-git` — Git workflow automation
- `/summarize-git-log` — Generate changelogs
- `/blog` — Draft and polish blog posts
